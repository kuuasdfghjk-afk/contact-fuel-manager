# 2WEEKコンタクト＆社用ガソリンカード期限管理 Webアプリ

単一HTMLプロトタイプと初期登録データを引き継ぎ、**SQLiteデータベースによるメンバー間リアルタイム同期（SSE）**および**毎朝8:00自動実行Cronジョブ（メール通知 / Web Push通知）**へ拡張したフルスタックWebアプリケーションです。

## 主な機能

1. **👁️ 名前登録式の2WEEKコンタクト交換期限管理**
   - 任意のメンバー名（シンジロウ、ユリなど）で複数人を登録・編集・削除可能
   - 開封日から14日後の交換期限を自動計算し、残り日数プログレスゲージ＆3日前アラート表示
   - ワンタップ「今日新しいレンズに交換（+14日リセット）」ボタン
   - LINE共有テキストコピー・LINEアプリ直接送信・Googleカレンダーワンタップ登録リンク生成

2. **⛽ 距離メモ不要（Zero-Tracking）の社用ガソリンカード私用分除外＆精算期限管理**
   - **モード①：固定ルート（往復km）回数タップ合算**による業務給油上限（L / 円）＆私用超過分の自動算出
   - **モード②：ガソリンスタンド現場での「定量・定額ストップ給油」計算**（業務日数 × 1日平均km ÷ 燃費）
   - **モード③：満タン給油後の「業務日数 vs 休日私用日数」スライダー按分**による私用自己負担額の控除計算
   - **精算期限管理リスト**：未精算レコードの期限カウントダウン、精算済ステータス切替、LINE共有・カレンダー登録

3. **🔄 リアルタイム同期 ＆ 🔔 毎朝8:00 自動プッシュ通知（メール & Web Push）**
   - **Server-Sent Events (SSE)** により、PC・スマホの複数ブラウザ間でデータをリアルタイム同期
   - **Web Push通知（VAPID + Service Worker）**：外部有料サービス不要・完全無料でブラウザ/スマホへネイティブ通知を配信
   - **メール自動通知（SMTP / Gmail対応）**：交換期限3日前〜超過のコンタクト対象メンバー（`kuuasdfghjk@gmail.com`, `yuri.dream1105@gmail.com` 等）および精算期限3日前以内のガソリン記録を毎朝8:00に自動送信

## 起動方法

```bash
cd /Users/kuutorii/.gemini/antigravity/scratch/contact-fuel-manager
/usr/bin/python3 server.py
```

- PCブラウザから: `http://localhost:8080`
- 同じWi-Fi内のスマホから: 画面上部に表示される `http://<MacのIPアドレス>:8080` にアクセスするとリアルタイム同期されます。
- コマンドラインから朝8:00の通知ジョブを単発実行する場合:
  ```bash
  /usr/bin/python3 server.py --run-cron
  ```
